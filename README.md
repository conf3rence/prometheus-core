# Prometheus Core v5.0.0

Программный комплекс для симуляции переноса гамма-излучения, заряженных частиц и нейтронов с верификацией по эталонным базам данных (NIST, ENDF/B).

## 🚀 Что нового в v5.1.0
*   **CSDA:** Устранен баг с двойным умножением на плотность в тяжелых средах.
*   **SOBP:** Оптимизирован подбор весов (NNLS) для протонной терапии (до 60 пучков, нормировка по среднему).
*   **2D-рассеяние:** Скорректирован расчет координат по формуле Хайленда для латерального страгглинга.
*   **Валидация NIST:** Прямой расчет сечений XCOM для гамма-квантов (>1 МэВ) и лог-лог сплайны/поправки для протонов в PSTAR.
*   **UI:** Добавлен прогресс-бар на Splash Screen, возвращена Dev-Консоль, исправлены разделы интерфейса.

## 🚀 Возможности

*   **Гамма-модуль (NIST XCOM):** 39 материалов, 50 изотопов, учет фотоэффекта, Комптона, когерентного рассеяния и пар. Сфера и плоский слой (до 3 слоев).
*   **Заряженные частицы (Бете-Блох + CSDA):** Протоны, альфа, дейтроны, электроны. Кривая Брэгга, SOBP, ЛПЭ, страгглинг по Бору, 2D-карта рассеяния.
*   **Нейтронный модуль (OpenMC / WSL 2):** Моноспектр, U-235, Cf-252, дозы по ICRP-74, сравнение замедлителей, 3D-визуализация (PyVista).
*   **Производительность:** Numba JIT (ускорение в 5–7 раз), мультипроцессинг, ~3 сек на 1 000 000 историй.
*   **Экспорт и интеграции:** HTML, JSON, CSV, NumPy, PDF-отчеты, Discord Webhooks, вкладка «Статистика», встроенная мини-IDE.

### Гамма-модуль (Монте-Карло, NIST XCOM)
*   **70 материалов** и **55 изотопов**.
*   Учет фотоэффекта, комптоновского и когерентного рассеяния, рождения пар через `xraylib`.
*   **Две геометрии:** сфера и плоский слой (до 3 слоев).
*   Расчет абсолютной дозы (Зв), обратного рассеяния и статистической погрешности.

### Модуль заряженных частиц (Бете-Блох + CSDA)
*   Расчет для протонов, альфа-частиц, дейтронов и электронов.
*   Учет страгглинга (по Бору) и визуализация Кривой Брэгга.
*   **SOBP** и **Сравнение ЛПЭ**.
*   2D-карта латерального рассеяния.

### 📤 Экспорт, диагностика и интеграции
*   **Экспорт данных:** Сохранение результатов в форматах HTML, JSON, CSV, NumPy Matrix (`.npy`), а также формирование **ZIP-архива для баг-репортов** (логи, конфигурация и системная информация).
*   **Отчетность:** Генерация детальных PDF-отчетов с графиками и таблицами верификации.
*   **Интеграции и утилиты:** Уведомления через Discord Webhooks, встроенная вкладка «Статистика», мини-IDE и профайлер Монте-Карло.

### ⚡ Оптимизация
*   **Numba JIT-компиляция** и **мультипроцессинг**.
*   Высокое быстродействие при расчете миллионов историй..

## 🧪 Верификация

| Модуль | Источник | Расхождение |
|--------|----------|-------------|
| Гамма (сечения) | NIST XCOM | < 0.01 % |
| Гамма (транспорт) | Закон Бугера | < 0.02 % |
| Протоны (пробег) | NIST PSTAR | 0.08 % |
| Тяжёлые ионы | SRIM | 0.03 % |

*Встроенный валидатор NIST и Центр тестирования доступны в меню «Справка».*

## 📦 Готовые сборки (Releases)
*   **Lite (v5.1.0):** Только Гамма и Заряженные. Работает «из коробки» (не требует Docker/WSL).
*   **Full (v5.1.0):** Все модули (включая Нейтроны). **Требует Docker Desktop**.

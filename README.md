# Prometheus Core v5.0.0

Программный комплекс для симуляции переноса гамма-излучения, заряженных частиц и нейтронов с верификацией по эталонным базам данных (NIST, ENDF/B).

## 🚀 Что нового в v5.0.0
*   **Docker-интеграция:** Нейтронный модуль (OpenMC) теперь работает в изолированном Docker-контейнере. Больше не нужно настраивать WSL.
*   **Медицинская физика (Заряженные):** Добавлен расчет **SOBP** (Spread-Out Bragg Peak) — формирование плато для протонной терапии. Добавлено сравнение тормозных способностей (ЛПЭ) протона и электрона.
*   **Вкладка «Статистика»:** История всех расчетов с возможностью экспорта в CSV/JSON и визуализацией распределения.
*   **Нейтроны (OpenMC):** Добавлен режим **Сравнения замедлителей** (Вода, Графит, Тяжелая вода) на одном графике.
*   **PDF-отчеты:** Универсальная система генерации PDF с графиками, параметрами и поддержкой кириллицы (во всех трех модулях).
*   **Мониторинг Discord:** Отправка логов расчетов в `#radiation-logs` и системных ошибок в `#system-alerts` через Webhooks.
*   **Интерфейс:** Новая киберпанк-заставка, цветные логи (HTML), защита от зависаний (QThread).
*   **Физика (Критическое исправление):** Устранены выбросы дозы (clamp индексов), исправлен Compton (NaN), переписан расчет массы слоев (геометрический интеграл). Починена база данных NIST на высоких энергиях (xraylib).
*   **Пасхалка:** Секретная вкладка с обратным отсчетом до GTA VI.

## 🚀 Возможности

### Гамма-модуль (Монте-Карло, NIST XCOM)
*   **39 материалов** и **50 изотопов**.
*   Учет фотоэффекта, комптоновского рассеяния, когерентного рассеяния и рождения пар.
*   **Две геометрии:** сфера и плоский слой (до 3 слоев защиты).
*   Расчет абсолютной дозы (Зв), обратного рассеяния, статистической погрешности.

### Модуль заряженных частиц (Бете-Блох + CSDA)
*   Расчет для протонов, альфа-частиц, дейтронов и электронов.
*   Учет страгглинга (по Бору), визуализация Кривой Брэгга.
*   **SOBP** (Протонная терапия) и **Сравнение ЛПЭ**.
*   2D-карта латерального рассеяния (Highland formula).

### Нейтронный модуль (OpenMC через Docker или WSL 2)
*   Моноэнергетический спектр, U-235, Cf-252.
*   Расчет эквивалентной дозы по ICRP-74.
*   **Сравнение эффективности замедлителей**.
*   3D-визуализация облака нейтронов (PyVista).

### ⚡ Оптимизация
*   **Numba JIT-компиляция:** ускорение ~5-7 раз.
*   **Мультипроцессинг:** 4 процесса в CLI, 1 процесс в GUI (защита от зависаний).
*   **Время расчёта:** 1 000 000 историй за **~3 секунды**.

### 📤 Экспорт и Интеграции
*   **HTML, JSON, CSV, NumPy Matrix (.npy)**.
*   **PDF-отчеты** с графиками и верификацией.
*   **Discord Webhooks** (уведомления о расчетах и ошибках).
*   **Вкладка "Статистика"** с историей и экспортом.

## 🧪 Верификация

| Модуль | Источник | Расхождение |
|--------|----------|-------------|
| Гамма (сечения) | NIST XCOM | < 0.01 % |
| Гамма (транспорт) | Закон Бугера | < 0.02 % |
| Протоны (пробег) | NIST PSTAR | 0.08 % |
| Тяжёлые ионы | SRIM | 0.03 % |

*Встроенный валидатор NIST и Центр тестирования доступны в меню «Справка».*

## 📦 Готовые сборки (Releases)
*   **Lite (v5.0.0):** Только Гамма и Заряженные. Работает «из коробки» (не требует Docker/WSL).
*   **Full (v5.0.0):** Все модули (включая Нейтроны). **Требует Docker Desktop**.

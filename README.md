# Prometheus Core v5.0.0

Программный комплекс для симуляции переноса гамма-излучения, заряженных частиц и нейтронов с верификацией по эталонным базам данных (NIST, ENDF/B).

## 🚀 Что нового в v5.0.0
*   **Docker-интеграция:** Нейтронный модуль (OpenMC) теперь работает в изолированном Docker-контейнере. Больше не нужно настраивать WSL.
*   **Вкладка «Статистика»:** История всех расчетов с экспортом в CSV/JSON и визуализацией распределения.
*   **Медицинская физика (Заряженные):** Добавлен расчет **SOBP** (Spread-Out Bragg Peak) с формированием плато для протонной терапии. Добавлено сравнение ЛПЭ протона и электрона.
*   **Нейтроны (OpenMC):** Добавлен режим **Сравнения замедлителей** (Вода, Графит, Тяжелая вода) на одном графике.
*   **PDF-отчеты:** Генерация красивых PDF с графиками, параметрами и поддержкой кириллицы (во всех трех модулях).
*   **Мониторинг Discord:** Отправка логов расчетов в `#radiation-logs` и системных ошибок в `#system-alerts` через Webhooks.
*   **Интерфейс:** Новая киберпанк-заставка, цветные логи, защита от зависаний (QThread).
*   **Физика (Критическое исправление):** Устранены выбросы дозы (clamp индексов), исправлен Compton (NaN), переписан расчет массы слоев (геометрический интеграл). Починена база данных NIST на высоких энергиях (xraylib).
*   **Пасхалка:** Секретная вкладка с обратным отсчетом до GTA VI.

## 🚀 Возможности

### Гамма-модуль (Монте-Карло, NIST XCOM)
*   **39 материалов** в базе (вода, свинец, вольфрам, морская вода, борсодержащий полиэтилен и др.).
*   **50 изотопов** (Cs-137, Co-60, Am-241, Na-24, Pu-239, Cf-252, U-235 и др.).
*   Транспорт фотонов с учётом **фотоэффекта**, **комптоновского рассеяния**, **когерентного рассеяния** и **рождения пар**.
*   **Две геометрии:** точечный источник в сфере и мононаправленный пучок в плоском слое.
*   **Многослойная защита:** до 3 слоёв разных материалов.
*   **Расчёт абсолютной дозы** (в Зивертах), обратного рассеяния и статистической погрешности.

### Модуль заряженных частиц (Бете-Блох + CSDA)
*   Расчёт тормозной способности и пробега для протонов, альфа-частиц, дейтронов и электронов.
*   **Учёт страгглинга** (флуктуации потерь энергии по Бору).
*   **Кривая Брэгга:** Визуализация пика энерговыделения.
*   **SOBP (Протонная терапия):** Построение ровного терапевтического плато.
*   **2D-карта латерального рассеяния** (Highland formula).
*   **Эквивалентная доза в Зивертах** (коэффициенты wR по ICRP-74).

### Нейтронный модуль (OpenMC через Docker / WSL 2)
*   Моноэнергетический спектр, U-235, Cf-252.
*   Спектры замедления, тепловой пик, 2D-карты потока.
*   **Сравнение эффективности замедлителей** (Вода, Графит, D2O).
*   **Расчёт эквивалентной дозы** по ICRP-74.
*   3D-визуализация облака тепловых нейтронов (PyVista).

### ⚡ Оптимизация
*   **Numba JIT-компиляция:** ускорение ~5-7 раз.
*   **Мультипроцессинг:** 4 процесса в CLI, 1 процесс в GUI (защита от зависаний интерфейса).
*   **Время расчёта:** 1 000 000 историй за **~3 секунды** (на 4-ядерном CPU).

### 📤 Экспорт и Интеграции
*   **HTML, JSON, CSV, NumPy Matrix (.npy)**.
*   **PDF-отчеты** с графиками и верификацией.
*   **Discord Webhooks** (уведомления о расчетах и ошибках).
*   **Вкладка "Статистика"** с историей и экспортом.

## 🧪 Верификация

| Модуль | Источник | Расхождение |
|--------|----------|-------------|
| Гамма (сечения) | NIST XCOM | < 0.01 % |
| Гамма (транспорт) | Закон Бугера | < 0.02 % |
| Протоны (пробег) | NIST PSTAR | 0.08 % |
| Тяжёлые ионы | SRIM | 0.03 % |

*Встроенный валидатор NIST и Центр тестирования доступны в меню «Справка».*

## 📦 Готовые сборки (Releases)
*   **Lite (v5.0.0):** Только Гамма и Заряженные. Работает «из коробки» (не требует Docker/WSL).
*   **Full (v5.0.0):** Все модули (включая Нейтроны). **Требует Docker Desktop**.

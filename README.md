# Prometheus Core v3.1.0

Программный комплекс для симуляции переноса гамма-излучения, заряженных частиц и нейтронов с верификацией по эталонным базам данных (NIST, ENDF/B).

## 🚀 Что нового в v3.1.0
*   **Интерфейс:** Добавлена функция «Развернуть» для графиков (плавный зум колесиком и панорамирование). Исправлен выбор материалов (двойной клик в окне поиска).
*   **Заряженные частицы:** Добавлена классическая **Кривая Брэгга** и **Гистограмма страгглинга** (разброс пробегов).
*   **Нейтроны:** Реализован расчет **эквивалентной дозы** (ICRP-74) и **многогрупповой анализ** потока (Тепловые, Резонансные, Быстрые).
*   **База данных:** Добавлен изотоп **U-235**. Пересчитаны сечения с учетом рождения пар (Pair Production).

## 🚀 Возможности

### Гамма-модуль (Монте-Карло, NIST XCOM)
*   **39 материалов** в базе (вода, свинец, вольфрам, морская вода, борсодержащий полиэтилен и др.).
*   **49 гамма-изотопов** (Cs-137, Co-60, Am-241, Na-24, Pu-239, Cf-252, U-235 и др.).
*   Транспорт фотонов с учётом **фотоэффекта**, **комптоновского рассеяния**, **когерентного рассеяния** и **рождения пар**.
*   **Две геометрии:** точечный источник в сфере и мононаправленный пучок в плоском слое.
*   **Многослойная защита:** до 3 слоёв разных материалов.
*   **Расчёт абсолютной дозы** (в Зивертах) с учётом активности и времени экспозиции.
*   **1D-срез (Line Profile):** Возможность строить профиль интенсивности вдоль любой линии 2D-карты (в Dev-версии).

### Модуль заряженных частиц (Бете-Блох + CSDA)
*   Расчёт тормозной способности и пробега для протонов, альфа-частиц, дейтронов и электронов.
*   **Учёт страгглинга** (флуктуации потерь энергии).
*   **Кривая Брэгга:** Визуализация пика энерговыделения.
*   **Эквивалентная доза в Зивертах** (коэффициенты wR по ICRP-74).
*   Режим ручного ввода параметров среды (Z, A, плотность, I).

### Нейтронный модуль (OpenMC через WSL)
*   Запуск OpenMC в WSL 2 (Linux).
*   Спектры замедления, тепловой пик, 2D-карты потока.
*   **Расчёт эквивалентной дозы** по ICRP-74.
*   **Многогрупповой поток:** разделение на тепловые, резонансные и быстрые нейтроны.
*   Ограничение по энергии — 20 МэВ (библиотека ENDF/B).

### ⚡ Оптимизация
*   **Numba JIT-компиляция:** ускорение ~5-7 раз.
*   **Мультипроцессинг:** 4 процесса через `multiprocessing.Pool`. Итоговое ускорение до **10x**.
*   **Время расчёта:** 1 000 000 историй за **~3 секунды** (на 4-ядерном CPU).

### 📤 Экспорт
*   **HTML** (со всеми графиками Base64), **JSON**, **CSV**, **NumPy Matrix (.npy)**.

## 🧪 Верификация

| Модуль | Источник | Расхождение |
|--------|----------|-------------|
| Гамма (сечения) | NIST XCOM | < 0.01 % |
| Гамма (транспорт) | Закон Бугера | < 0.02 % |
| Протоны (пробег) | NIST PSTAR | 0.08 % |
| Тяжёлые ионы | SRIM | 0.03 % |

*Встроенный валидатор NIST можно запустить в меню «Справка» (в Dev-версии).*
